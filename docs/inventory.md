## 2. Milvus Collection

**Collection:** `aic25_keyframes` (from `config.py: COLLECTION_NAME`)

| Field | Type | Notes |
|---|---|---|
| `id` | VARCHAR(32), PK | Format `"L21_V001/001"` (video/keyframe_idx zero-padded to 3) |
| `video_name` | VARCHAR(16) | e.g. `"L21_V001"` |
| `keyframe_idx` | INT32 | = n from CSV (1-based keyframe number) |
| `frame_idx` | INT64 | Actual video frame index, mapped from `map-keyframes/*.csv` |
| `pts_time` | FLOAT | Presentation timestamp in seconds |
| `fps` | FLOAT | Frames per second of source video |
| `clip_vector` | FLOAT_VECTOR(512) | **TSBIR/TASK-former** image embedding (ViT-B-16) — for sketch search |
| `text_vector` | FLOAT_VECTOR(768) | **SigLIP2 image** embedding (`google/siglip2-base-patch16-512`) — for text search |
| `objects` | ARRAY\<VARCHAR(64)\>, max 20 | YOLO11 COCO labels (e.g. `"person"`, `"car"`) |
| `ocr` | VARCHAR(4096) | Florence-2 OCR text (often missing diacritics) |

**Indexes:** Both vector fields use HNSW (M=32, efConstruction=256), COSINE metric. Search ef=512.

**Approximate size:** ~177k keyframes, ~873 videos (L21–L30). Blank/black transition frames filtered during ingest.

### Key invariant

`keyframe_idx` (n) ≠ `frame_idx`. Always map through `map-keyframes/{video}.csv`.

## 3. Encoders

| Encoder | Model | Use | Output dim |
|---|---|---|---|
| **SigLIP2** (text) | `google/siglip2-base-patch16-512` | Text queries → `text_vector` search | 768 |
| **SigLIP2** (image) | same | Image-by-example → `text_vector` search | 768 |
| **TSBIR / TASK-former** (image only) | OpenCLIP `ViT-B-16` + `tsbir_model_final.pt` (2.6 GB) | Sketch → `clip_vector` search | 512 |

**Critical:** The `text_vector` field was built with SigLIP2 **image** encoder during ingest. Therefore text queries must use the SigLIP2 **text** encoder, not OpenAI CLIP.

**TSBIR bug:** The current `CLIPEncoder` builds the model with default GELU activation, but TSBIR was trained with **QuickGELU**. This causes ~cos 0.98 mismatch vs. indexed vectors. Must rebuild with `quick_gelu=True` on the vision tower only.

**Offline mode:** `HF_HUB_OFFLINE=1` and `TRANSFORMERS_OFFLINE=1` set in `encoder.py`. Models must be pre-downloaded to HF cache via `backend/scripts/download_models.py`.

## 10. Shot Data

TransNetV2 was run externally. **No scene/shot file exists in the repo.** Until the user provides one:
- A "shot" = the keyframe ± 1 neighbor keyframe in the same video (by `pts_time`).
- `shot_id` is left empty in traces.
